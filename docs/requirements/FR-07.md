# FR-07 Authentication

Access to the dashboard is restricted to members of the configured GitHub organisation and owners of tracked forks. Authentication is via GitHub OAuth. If no organisation is configured, the org check is omitted without producing errors.

**Acceptance criteria:**

- Unauthenticated users are redirected to a login page; no dashboard content is accessible without a valid session
- Login is handled via GitHub OAuth; no separate credentials are managed by the application
- After login, access is granted if the user is a member of the configured GitHub org, or owns one of the tracked forks
- Users who meet neither condition see a clear "access denied" message and cannot proceed
- A logged-in user can log out, which ends their session immediately
- The webhook endpoint is exempt from browser-session authentication; it uses HMAC signature verification instead
