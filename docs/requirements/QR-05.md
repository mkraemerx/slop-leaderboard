# QR-05 Security

**Acceptance criteria:**

- All pages except the login flow and webhook endpoint require an authenticated session (FR-07)
- Git operations never pass user-supplied strings to a shell; only library APIs are used
- Repository storage paths are validated to prevent path traversal
- Platform API tokens and OAuth secrets are stored as configuration, never logged or exposed in the UI
- Webhook endpoints with a configured secret reject requests that lack a valid HMAC-SHA256 signature
