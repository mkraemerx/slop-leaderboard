# FR-03 Commit Metrics

For each commit the following data is captured: author name, author email, timestamp, lines added, lines removed, number of files changed, whether it is a merge commit, and which branches and tags contain that commit at analysis time.

Each changed file is classified into one of four categories based on its path and extension:

- **Code** — source files in a recognised programming language (e.g. `.py`, `.js`, `.ts`, `.java`, `.go`, `.rb`, `.rs`)
- **Tests** — files whose path or name matches test conventions (e.g. `test_*.py`, `*_test.go`, `*.spec.ts`, files under `test/`, `tests/`, `__tests__/`, `spec/`)
- **Docs** — documentation files (e.g. `*.md`, `*.rst`, `*.adoc`, files under `docs/`)
- **Config / infra** — deployment and configuration files (e.g. `Dockerfile*`, `*.yml`, `*.yaml`, `*.toml`, `*.json` outside of source trees, files under `.github/`)

Per-commit, the lines added and removed are broken down by these four categories in addition to the totals.
