# FR-02 Git Analysis

The system clones and analyses each tracked fork to extract per-commit contribution data.

**Acceptance criteria:**

- A newly discovered or manually added fork is enqueued for full analysis immediately
- On every subsequent sync, only commits not yet seen are processed; existing data is not re-imported
- Analysis failures leave existing data intact and are visible as an error state on that fork
- Merge commits are stored but do not count toward leaderboard scores
