# FR-01 Root Repository & Fork Tracking

The system is configured with one root repository. It discovers and tracks all forks of that root. A fork represents one author's workspace.

**Acceptance criteria:**

- The root repository is configured by providing its URL and a platform API token (GitHub or GitLab)
- The system discovers all forks of the root automatically and adds them to the tracked set
- Forks can also be added manually by URL (for platforms without API support, or private forks not returned by the API)
- The tracked list shows each fork with its owner name, sync status, and when it was last analysed
- Removing the root repository removes all forks and their data
