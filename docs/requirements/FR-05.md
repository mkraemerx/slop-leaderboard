# FR-05 Leaderboard

The leaderboard ranks authors (fork owners) by a score derived from their commit activity.

**Score formula:** `commits × 10 + insertions × 0.01 + active_days × 50` (rounded to integer)

**Columns:** Rank · Author · Commits · Lines Changed · Tests Added · Refactor Ratio · Exercise Breadth · First Submissions · Active Days · Score

- **Lines Changed** — total insertions + deletions; hovering reveals a breakdown by category (code / tests / docs / config) as a small bar or percentage list
- **Tests Added** — net lines added in test-classified files across all commits in scope
- **Refactor Ratio** — deletions ÷ (insertions + deletions), shown as a percentage; higher means more cleanup relative to new code written
- **Exercise Breadth** — number of distinct exercises the author has at least one commit on
- **First Submissions** — number of exercises where this author was the first to push a commit

**Acceptance criteria:**

- By default the leaderboard covers all commits across all forks for all time
- The leaderboard can be scoped to a specific exercise; only commits on that exercise's branch or tag are counted
- The time window can be set to 7 days, 30 days, 90 days, or all-time
- Hovering over the Lines Changed cell reveals the per-category breakdown (code / tests / docs / config) as proportions
- Authors with equal scores are ordered by commit count
- The leaderboard refreshes automatically in the background without user interaction
