# FR-06 Solution Comparison

For a selected exercise, the system shows how author solutions differ from each other in size and structure.

**Metrics shown per fork:**

- Lines added and removed relative to the root repository's base for that branch
- Number and names of files changed
- A structural similarity score against every other fork: what proportion of changed files overlap

**Acceptance criteria:**

- The comparison view lists all forks that have the selected exercise branch or tag
- Each fork entry shows its diff size and the files it changed relative to the root
- Forks that changed largely the same files are surfaced as structurally similar; forks with little overlap are surfaced as having taken a different approach
- The comparison view is accessible per exercise from the exercise list
