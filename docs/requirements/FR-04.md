# FR-04 Exercises

An exercise is any branch name or tag that appears in at least one fork but is absent from the root repository. Exercises are discovered automatically — no manual definition is needed. The status of the main branch is also compared by the end of each day, independent of the tags.

**Acceptance criteria:**

- After each fork sync, branches and tags not present in the root are surfaced as known exercises
- The exercise list shows each discovered name and how many forks currently have it
- The exercise list shows which author was first to push a commit to each exercise branch
- An exercise disappears from the list when no tracked fork retains that branch or tag
